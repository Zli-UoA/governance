# Zli Governance Repository

このリポジトリは、「Zli」の公式ルールブックです。
Zli がどんな団体で、どう運営されているか、すべてここにまとめてあります。コミュニティの透明性を保つための大切な場所です。

## 📜 ドキュメント一覧

Zli のルールは、その重要度と変更のプロセスに応じて 3 つのレイヤーに分かれています。

### ⚖️ Governance Layer (ガバナンス層)

総会で決議する、団体の憲法です。
団体の根幹に関わる最も重要なルールであり、変更には全正会員による総会の承認が必要です。

[Zli 規約](bylaws.md)

団体の目的、会員、役員などを定める、Zli の最も基本的なルールブックです。

[Zli 会計規則](accounting_rules.md)

予算、決算、会費など、団体のお金に関する根本的なルールです。

### 🏛️ Directive Layer (ディレクティブ層)

理事会で決議する、運営の公式な方針です。
団体の日々の運営を公式に進めるための重要なガイドラインであり、変更や改善は運営チームである理事会の決議によって行われます。

[Zli 理事会規程](board_regulations.md)

運営会議の進め方や、物事の決め方に関する公式ルールです。

[Zli 協賛・契約ガイドライン](sponsorship_guidelines.md)

スポンサー様との関係性や、外部との契約手続きに関するガイドラインです。

[Zli 個人情報保護規程](privacy_policy.md)

メンバーからお預かりした個人情報を守るための大切なルールです。

[Zli コントリビューター行動規範](code_of_conduct.md)

誰もが安心して活動に参加するための、コミュニティで守るべき行動のお約束です。

### 🚀 Operations Layer (オペレーション層)

担当者が自由に作成・更新する、現場の実践マニュアルです。
日々の活動をスムーズに進めるための具体的な手順書やノウハウ集であり、公式な承認を必要とせず、各担当者が活動をより良くするために作成・更新します。

(例) イベント運営マニュアル

(例) GitHub 経費申請フロー

(例) 新メンバー向けオンボーディング資料

(例) 広報・SNS 運用ガイドライン

## 🤝 貢献について
